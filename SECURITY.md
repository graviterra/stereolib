# Security

Security fixes are accepted for the development branch. No stable release is designated.

Use GitHub private vulnerability reporting when available. Otherwise, open a minimal issue
requesting private contact with the maintainers. Do not include credentials, private molecular
data, or exploit details in a public issue.

Include the affected commit, command or API, a minimal non-sensitive reproducer, and the expected
behavior. Ordinary proof gaps and disagreements about chemical interpretation can be reported
as proof/specification or chemistry issues.
